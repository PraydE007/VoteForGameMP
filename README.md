# 🎮 VoteForMP

> **Launch server, open the page, connect, add games into list and vote for them.**

Вебсервіс для компанії, що допомагає швидко та справедливо обрати спільну гру. Клієнтська частина повністю статична й працює на **GitHub Pages**, а бекенд на **Python (FastAPI)** керує сесіями та в реальному часі підраховує результати голосування.

---

## ✨ Особливості

- ⚡ **Без складних налаштувань:** запуск бекенда в один клік (`start_backend.bat`).
- 🌐 **GitHub Pages Ready:** фронтенд не потребує збірки (HTML5, сучасний CSS3, чистий JavaScript).
- 🔗 **Швидкі запрошення:** генерація посилань зі збереженням адреси сервера та коду кімнати.
- 🎮 **Гнучкий список ігор:** додавання варіантів по одному або списком (bulk add).
- ⭐ **Система оцінювання:** кожен учасник ставить оцінку кожній грі від 1 до 5 балів.
- 🏆 **Автоматичний підсумок і нічия:** щойно всі проголосували, результати відкриваються автоматично. Якщо кілька ігор набрали однаковий найвищий середній бал, відображаються всі переможці.
- 🌍 **Гра через інтернет:** можливість організувати спільне мережеве з'єднання через Porthole (Steam), щоб користуватися сайтом і грати разом.

---

## 🚀 Швидкий старт

### 1. Запуск бекенда (Python)

Переконайтеся, що у вас встановлено Python 3.10 або новішої версії.

**На Windows (в один клік):**

Запустіть файл [`start_backend.bat`](./start_backend.bat).

**Або через термінал:**

```bash
pip install -r backend/requirements.txt
python backend/main.py
```

Після запуску бекенд буде доступний на локальному комп'ютері за адресою:

`http://localhost:8000`

> **Важливо:** `localhost` доступний лише на комп'ютері, де запущено бекенд. Щоб друзі могли підключитися до нього через інтернет, налаштуйте мережеве з'єднання за допомогою одного зі способів у розділі [Гра через інтернет](#-гра-через-інтернет).

---

### 2. Запуск клієнта

- **Локально:** відкрийте файл [`index.html`](./index.html) у браузері.
- **Онлайн (GitHub Pages):**
  1. Завантажте репозиторій на GitHub.
  2. Відкрийте **Settings → Pages**.
  3. У пункті **Branch** виберіть `main`, папку `/ (root)` та натисніть **Save**.
  4. Сайт буде доступний за адресою `https://<username>.github.io/<repo>/`.

Фронтенд на GitHub Pages лише відображає інтерфейс. Сам бекенд повинен працювати окремо на комп'ютері хоста або сервері, доступному учасникам.

## 🌐 Гра через інтернет

Щоб сайт VoteForMP працював у всіх учасників, кожен клієнт повинен мати доступ до бекенда хоста. Крім того, якщо ви запускаєте мережеву гру, учасники повинні мати з'єднання між собою відповідно до вимог самої гри.

### Варіант 1 — Porthole (Steam, рекомендовано)

**Рекомендований спосіб для гри з друзями — використовувати [Porthole у Steam](https://store.steampowered.com/).** Він дає змогу організувати мережеве з'єднання між комп'ютерами для використання локально доступних сервісів та ігор через створене з'єднання, залежно від конфігурації Porthole.

#### Налаштування VoteForMP

1. Усі учасники встановлюють і запускають Porthole через Steam.
2. Організуйте з'єднання між комп'ютером хоста та комп'ютерами друзів відповідно до інструкцій Porthole.
3. Хост запускає бекенд VoteForMP через `start_backend.bat`.
4. Переконайтеся, що бекенд доступний через мережеве з'єднання Porthole.
5. Відкрийте сайт VoteForMP на GitHub Pages.
6. У налаштуваннях сервера (іконка ⚙️) вкажіть адресу бекенда, доступну через Porthole.
7. Перевірте статус підключення. Після успішного з'єднання можна створювати кімнати, запрошувати друзів і голосувати за ігри.

**Важливо щодо адреси сервера:**

- `http://localhost:8000` або `http://127.0.0.1:8000` звертається до комп'ютера, на якому відкрито браузер, а не автоматично до комп'ютера хоста.
- Якщо Porthole налаштований так, що на комп'ютері кожного учасника доступний локальний проксі, який перенаправляє з'єднання до хоста, можна використовувати адресу цього проксі.
- Якщо локального проксі немає, потрібно вказати адресу хоста, доступну через мережу Porthole, та порт бекенда.
- Бекенд має слухати мережевий інтерфейс, через який надходять з'єднання. Якщо він прив'язаний лише до `127.0.0.1`, інші комп'ютери не зможуть звернутися до нього без відповідного проксі або перенаправлення.

#### Налаштування мережевої гри

Porthole можна використовувати не лише для доступу до VoteForMP, а й для мережевого з'єднання в самих іграх.

1. Спочатку встановіть з'єднання між гравцями через Porthole.
2. Хост запускає гру або створює сервер відповідно до інструкцій конкретної гри.
3. Інші гравці підключаються до хоста через адресу та порт, доступні в мережі Porthole.
4. Якщо гра використовує LAN-пошук, широкомовні пакети або окремі порти, переконайтеся, що Porthole та налаштування гри підтримують необхідний тип трафіку.

> **Примітка:** точні адреси, порти та налаштування залежать від конфігурації Porthole і конкретної гри. Сам факт підключення через Porthole не гарантує автоматичної роботи LAN-пошуку в кожній грі.

### Варіант 2 — Cloudflare Tunnel

Альтернативний спосіб надати друзям доступ до бекенда через публічну HTTPS-адресу — Cloudflare Tunnel.

```bash
cloudflared tunnel --url http://localhost:8000
```

Скопіюйте згенеровану HTTPS-адресу, наприклад `https://example.trycloudflare.com`, і вкажіть її в налаштуваннях сервера на сайті.

Цей спосіб призначений для доступу до веббекенда. Він **не створює мережу для спільної гри** і не замінює засоби підключення, необхідні самій грі.

### Варіант 3 — Ngrok

Ще один спосіб відкрити доступ до локального бекенда — Ngrok.

```bash
ngrok http 8000
```

Скопіюйте отриману HTTPS-адресу та вкажіть її в налаштуваннях сервера на сайті.

Як і Cloudflare Tunnel, Ngrok надає доступ до вебсервісу, але сам по собі не забезпечує мережеве з'єднання для багатокористувацької гри.

### Важливо: HTTPS і підключення до бекенда

GitHub Pages працює через HTTPS. Якщо сайт відкритий через HTTPS, браузер може блокувати запити до бекенда через звичайний HTTP як змішаний контент.

Тому:

- Для публічних HTTPS-тунелів використовуйте видану HTTPS-адресу.
- Для Porthole перевірте, чи підтримує ваша схема підключення HTTPS або інший спосіб доступу, дозволений браузером.
- Якщо бекенд доступний лише через HTTP-адресу на кшталт `http://127.0.0.1:8000`, це не означає, що сайт на GitHub Pages зможе звернутися до нього: браузер може заблокувати запит.
- Якщо потрібен доступ до бекенда з HTTPS-сайту через Porthole, необхідно забезпечити сумісний із браузером спосіб підключення.

**Рекомендація:** для приватних ігрових сесій спочатку налаштуйте Porthole для мережевого з'єднання між учасниками. Для доступу до бекенда VoteForMP додатково перевірте адресу сервера та сумісність з HTTPS.

## 🕹️ Як користуватися

1. **Connect:** відкрийте сайт і перевірте статус підключення до бекенда (зелений індикатор).
2. **Create / Join:** створіть нову сесію (ви станете хостом) або приєднайтеся за кодом кімнати. Натисніть «Скопіювати посилання» та надішліть його друзям.
3. **Add games:** додайте ігри, між якими обираєте.
4. **Vote:** хост запускає голосування. Кожен учасник оцінює кожну гру від 1 до 5 зірок та підтверджує свій вибір.
5. **Results:** щойно всі учасники проголосують, система виведе переможця або всіх переможців у разі нічиєї, а також детальну таблицю балів.
6. **Play:** після голосування підключіться до обраної гри. Якщо вона підтримує локальну або приватну мережеву гру, використовуйте Porthole та інструкції для підключення конкретної гри.

## 🛠️ Стек технологій

- **Backend:** Python 3, FastAPI, Uvicorn, Pydantic.
- **Frontend:** Vanilla HTML5, CSS3 (Custom Properties, Flexbox/Grid), Vanilla JavaScript (Fetch API, Live Polling).
- **Hosting:** GitHub Pages (Frontend) + локальний хост / VPS / тунель (Backend).
- **Networking:** Porthole (Steam) — рекомендований варіант для мережевого з'єднання між гравцями; Cloudflare Tunnel і Ngrok — альтернативи для доступу до веббекенда.
