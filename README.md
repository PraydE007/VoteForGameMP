# 🎮 VoteForMP — Сервіс голосування за спільні ігри

VoteForMP — це веб-додаток для компанії друзів, який дозволяє швидко та зручно обрати гру для спільної гри:
1. Клієнти заходять на статичний сайт (розміщений на **GitHub Pages**).
2. Вводять адресу Python-сервера (або переходять за готовим посиланням).
3. Створюють кімнату / сесію або приєднуються за кодом.
4. Додають список ігор (по одній або масово списком).
5. Кожен учасник ставить оцінку кожній грі від **1 до 5 балів**.
6. Коли всі проголосували — автоматично підраховуються результати та показується **найбільш обраний варіант** (якщо кілька ігор набрали однаково найвищий бал — відображаються **всі переможці**).

---

## 📁 Структура проєкту

```
VoteForMP/
├── index.html            # Головна сторінка (для GitHub Pages)
├── style.css             # Стилі (темна ігрова тема, адаптивний дизайн)
├── app.js                # Клієнтська логіка (автопідключення, опитування, вибір)
├── start_backend.bat     # Скрипт запуску бекенда в 1 клік на Windows
├── README.md             # Ця інструкція
└── backend/
    ├── main.py           # FastAPI сервер (CORS, кімнати, голосування, підрахунок)
    └── requirements.txt  # Залежності Python (fastapi, uvicorn, pydantic)
```

## 🚀 Швидкий запуск

### Крок 1. Запуск бекенда (Python)

1. Відкрийте папку проекту.
2. Запустіть файл **`start_backend.bat`** (двічі клікніть по ньому на Windows)  
   *Або через термінал:*
   ```bash
   pip install -r backend/requirements.txt
   python backend/main.py
   ```
3. Сервер запуститься на адресі: `http://localhost:8000`.

---

### Крок 2. Як грати з друзями через інтернет?

Оскільки сайт лежить на GitHub Pages (`https://...`), для гри з друзями через інтернет вашому локальному бекенду потрібна публічна адреса (бажано з HTTPS, щоб браузер не блокував Mixed Content).

Найпростіші безкоштовні варіанти:

#### Варіант А: Cloudflare Tunnel (швидко та безкоштовно)
```bash
# Якщо встановлено cloudflared:
cloudflared tunnel --url http://localhost:8000
```
Він видасть посилання вигляду: `https://xxxx.trycloudflare.com`.

#### Варіант Б: Ngrok (найпопулярніший)
```bash
ngrok http 8000
```
Він видасть публічне посилання: `https://xxxx.ngrok-free.app`.

#### Варіант В: Безкоштовний хостинг у хмарі (24/7)
Ви можете безкоштовно задеплоїти папку `backend` на [Render.com](https://render.com), [Railway.app](https://railway.app) або [Fly.io]. Команда запуску:
```bash
uvicorn main:app --host 0.0.0.0 --port $PORT
```

---

### Крок 3. Публікація клієнта на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `VoteForMP`).
2. Завантажте файли (`index.html`, `style.css`, `app.js`, `backend/`, тощо) у репозиторій:
   ```bash
   git init
   git add .
   git commit -m "Initial commit VoteForMP"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НІКНЕЙМ/VoteForMP.git
   git push -u origin main
   ```
3. На GitHub відкрийте ваш репозиторій:
   - Перейдіть у **Settings** -> **Pages**.
   - У розділі **Build and deployment** виберіть:
     - Branch: `main`
     - Folder: `/ (root)`
   - Натисніть **Save**.
4. За 1-2 хвилини ваш сайт буде доступний за адресою:
   `https://ВАШ_НІКНЕЙМ.github.io/VoteForMP/`

## 🎯 Як користуватися додатком

1. **Вхід на сайт:**
   - Відкрийте посилання на сайт.
   - Вкажіть адресу сервера (натиснувши іконку ⚙️ зверху або у полі налаштувань). Якщо граєте локально — `http://localhost:8000`, якщо з друзями — публічна адреса тунелю.
2. **Створення сесії:**
   - Введіть свій нікнейм і натисніть **"Створити кімнату"**.
   - З'явиться 6-значний код кімнати (наприклад, `VJIP00`).
   - Натисніть **"📋 Скопіювати посилання"** та надішліть його друзям у Discord/Telegram. Посилання вже містить адресу сервера і код кімнати, тому друзям достатньо просто перейти за ним!
3. **Додавання ігор:**
   - Усі учасники можуть пропонувати ігри (по одній або вставити список списком).
4. **Голосування:**
   - Хост тисне **"▶️ Почати голосування"**.
   - Кожен учасник ставить оцінку від 1 до 5:
     - `1` 🛑 — Зовсім не хочу
     - `2` 😕 — Не дуже
     - `3` 😐 — Зіграю, якщо всі захочуть
     - `4` 👍 — Хороший варіант
     - `5` 🔥 — Топ / Дуже хочу грати!
   - Натискає **"✅ Надіслати мій голос"**.
5. **Результати:**
   - Щойно останній учасник надішле свої оцінки — сайт автоматично перемикається на екран результатів!
   - **Найбільш обираємий варіант:** Гра з найвищим середнім балом виводиться на золотий п'єдестал.
   - **Якщо варіантів декілька (однакова оцінка):** Система виявляє нічию та виводить **усіх переможців** з однаковим найвищим балом!
   - Нижче відображається детальна рейтингова таблиця всіх ігор із кількістю голосів та сумарними балами.
   - Хост може натиснути **"🔄 Почати новий раунд"**, щоб провести нове голосування з цими або новими іграми.
